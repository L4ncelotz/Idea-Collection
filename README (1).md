# Idea Vault

> **Think it. Save it. Build it later.**

พื้นที่ส่วนตัวสำหรับเก็บไอเดียโปรเจกต์ที่คิดออกในแต่ละวัน เพื่อไม่ให้ไอเดียหายไป และกลับมาเปิดอ่านหรือเริ่มลงมือทำเมื่อไรก็ได้จากทุกอุปกรณ์

**สถานะเอกสาร:** Product concept / MVP scope (ยังไม่เลือกเทคโนโลยี)

## 1. ปัญหาที่ต้องการแก้

- เจอไอเดียน่าสนใจ แต่ยังไม่พร้อมเริ่มทำ และกลัวลืมในภายหลัง
- ไอเดียกระจัดกระจายอยู่ในแชต โน้ต หรือไฟล์หลายแห่ง
- เมื่อจะเริ่มทำจริง ต้องกลับมาเรียบเรียงแนวคิดและขอบเขตใหม่

## 2. แนวคิดหลัก

**หนึ่งไอเดีย = หนึ่งการ์ดสรุป + หนึ่ง README สำหรับรายละเอียด**

- **Title** — ชื่อสั้น ๆ ที่ทำให้จำได้ว่าเป็นโปรเจกต์อะไร
- **Description** — อธิบายสั้น ๆ ว่าทำอะไรและทำไปทำไม
- **README** — รายละเอียดแบบ Markdown เช่น แนวคิด ฟีเจอร์ และสิ่งที่อยากทำต่อ
- **Status** — `Idea`, `Building`, `Done` เพื่อดูว่าอยู่ในขั้นไหน

เปิดเว็บจากคอมพิวเตอร์หรือโทรศัพท์ก็สามารถดูและแก้ไขข้อมูลเดิมได้

## 3. ประสบการณ์ใช้งานที่ต้องการ

1. คิดไอเดียออก → กด **New Idea**
2. กรอกชื่อและคำอธิบายสั้น ๆ → **Save** ได้ทันที (ไม่บังคับเขียน README)
3. หากอยากขยายความ → เปิดไอเดียนั้นและเขียน README แบบ Markdown
4. กลับมาภายหลัง → ค้นหาชื่อหรือคำอธิบาย แล้วอ่านต่อจากจุดเดิม
5. เริ่มทำโปรเจกต์จริง → เปลี่ยนสถานะเป็น **Building**

**หลักการ:** บันทึกไอเดียใหม่ได้ภายในไม่กี่คลิก โดยไม่มีฟอร์มยาวหรือขั้นตอนที่ไม่จำเป็น

## 4. MVP — สิ่งที่ต้องมี

- [ ] ดูรายการไอเดียทั้งหมดเป็นการ์ด (ชื่อ, คำอธิบาย, สถานะ)
- [ ] สร้างไอเดียใหม่ด้วย Title และ Description
- [ ] เปิดดูและแก้ไขรายละเอียดของไอเดีย
- [ ] เขียน/แก้ README ด้วย Markdown และดู Preview ได้
- [ ] ค้นหาไอเดียจากชื่อและคำอธิบาย
- [ ] เปลี่ยนสถานะ Idea / Building / Done
- [ ] ลบไอเดียโดยมีหน้าต่างยืนยันก่อนลบ
- [ ] เข้าถึงไอเดียชุดเดียวกันได้จากหลายอุปกรณ์ด้วยบัญชีส่วนตัว

> **ขอบเขต MVP:** มีเพียง 2 หน้าหลัก — **Idea List** และ **Idea Detail / Edit**; การสร้างใหม่อาจเป็นหน้าต่างเล็ก ๆ (modal) บนหน้า List

## 5. สิ่งที่ยังไม่ทำ

- AI สร้างหรือวิเคราะห์ไอเดีย
- แนบไฟล์ รูปภาพ หรืออัปโหลดเอกสาร
- เชื่อมต่อ GitHub หรือสร้าง Repository อัตโนมัติ
- ระบบทีม แชร์ไอเดีย หรือ Collaboration
- Kanban, Timeline, Deadline, Task management
- ระบบหมวดหมู่ซับซ้อน คะแนนความสำคัญ หรือ Analytics
- Rich-text editor เต็มรูปแบบ

สิ่งเหล่านี้ค่อยพิจารณาหลังใช้ MVP จริง ไม่ใช่เงื่อนไขของเวอร์ชันแรก

## 6. หน้าจอหลัก

### Idea List

- หัวข้อ **Your Ideas**
- ปุ่ม **+ New Idea**
- ช่องค้นหา
- การ์ดแต่ละไอเดีย: Title, Description, Status
- Empty state เมื่อยังไม่มีไอเดีย

### Idea Detail / Edit

- Title, Description, Status ที่แก้ไขได้
- ส่วน README สำหรับเขียน Markdown พร้อมสลับ **Edit / Preview**
- ปุ่ม Save และ Delete

**แนวทาง UI:** Modern, Minimalist, Clean — อ่านง่าย ใช้งานบนมือถือได้ ไม่เพิ่มองค์ประกอบตกแต่งที่ไม่ช่วยให้งานสำเร็จ

## 7. ตัวอย่างหนึ่งไอเดีย

**Title:** Focus Garden  
**Description:** Pomodoro Timer ที่ต้นไม้ค่อย ๆ เติบโตตามเวลาที่โฟกัส  
**Status:** Idea

ตัวอย่างเนื้อหา README ของไอเดียนี้:

```md
# Focus Garden

## Concept
จับเวลาโฟกัสพร้อมสวนต้นไม้เล็ก ๆ ที่เติบโตเมื่อทำงานสำเร็จ

## Core Features
- Focus timer
- Plant growth animation
- บันทึกความคืบหน้า

## Later
- ต้นไม้หลายชนิด
- สถิติย้อนหลัง
```

## 8. ไอเดียเริ่มต้นที่ควรเก็บไว้

| Idea | คำอธิบายสั้น ๆ |
| --- | --- |
| TinyDiff | เปรียบเทียบ Text / JSON / Code สองฝั่งและไฮไลต์จุดต่าง |
| Focus Garden | Pomodoro Timer ที่ปลูกต้นไม้ตามเวลาโฟกัส |
| RepoShelf | แกลเลอรีโชว์ GitHub Repositories ของตัวเอง |
| DevPocket | เว็บรวมเครื่องมือเล็ก ๆ เช่น JSON Formatter, Base64, UUID |
| Streakly | บันทึกนิสัยรายวันและแสดง Heatmap |
| Tiny Dungeon | เกม Dungeon แบบ Turn-based ขนาดเล็ก |
| ValueCheck | เปรียบเทียบความคุ้มค่าระหว่างราคาและคะแนน Benchmark |

> รายการนี้เป็น **ตัวอย่างข้อมูลเริ่มต้น** ไม่ใช่ฟีเจอร์ที่ต้องทำให้ Idea Vault

## 9. นิยามว่า MVP เสร็จแล้ว

- เพิ่มไอเดียใหม่ได้รวดเร็วโดยไม่ต้องกรอก README
- ปิดเว็บแล้วเปิดใหม่ ข้อมูลยังอยู่
- เปิดจากอุปกรณ์อื่นด้วยบัญชีเดิม เห็นรายการที่บันทึกไว้
- แก้ไข README และดู Markdown Preview ได้
- ค้นหาไอเดียเก่าเจอและเปลี่ยนสถานะได้
